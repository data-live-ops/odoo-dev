Colearn Contact Metabase Integration

Seamlessly integrate Metabase data with Odoo contacts

Features

  • Connect to Metabase API and retrieve data from predefined questions/cards
  • Map Metabase data to Odoo contacts (res.partner)
  • Import students and parents from Metabase
  • Track student details, curriculum, grade, and lead stage
  • Monitor subscription status and details
  • Maintain parent-child relationships between contacts

Configuration

To configure this module:

  1. Go to Contacts > Metabase > Configuration
  2. Create a new Metabase configuration with your credentials
  3. Click "Test Connection" to verify your setup
  4. Configure the question IDs for different data types

Usage

To import contacts from Metabase:

  1. Go to Contacts > Metabase > Import Contacts
  2. Select your Metabase configuration
  3. Choose whether to import students, parents, or both
  4. Decide if you want to update existing contacts
  5. Click "Import" to start the process

To sync an individual contact:

  1. Open the contact form
  2. Click the "Sync from Metabase" button in the top-right corner
